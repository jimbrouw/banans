## What Was Done

### Problem
The plugin showed:  
> "No source-clip transcript was found on the active sequence."

This is a **hard Adobe platform limitation**: the UXP Transcript API (`Transcript.hasTranscript`, `Transcript.exportToJSON`) only works on source *clips* — it cannot read a sequence-level transcript generated by Premiere's "Transcribe Sequence" feature in the Text panel.

### Solution
Added a **file-import path** as the primary workaround:

1. In Premiere's Text panel → `...` menu → **Export to CSV File**
2. In RoughCut → click **Load transcript file** → select the CSV
3. RoughCut parses it and runs analysis

### Bugs Fixed

| Bug | Fix |
|-----|-----|
| Blank panel / UXP crash | `hostRuntime.ts` was registering `roughcutPanel: {}` — UXP requires `create` or `show` handler. Fixed: `{ show() {} }` |
| Speaker names showing as UUIDs | `normalizeTranscriptJson` now resolves UUIDs against `root.speakers[]` |
| `track.getTrackItems()` missing `await` | Added missing `await` in `collectItemTranscript` |
| `.prtranscript` files | Detected and rejected with clear error (format is proprietary — use CSV export instead) |
